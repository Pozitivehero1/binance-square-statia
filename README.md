# TikTok Auto Video — Mistral + Pexels

Готовый генератор англоязычных вертикальных роликов 1080×1920 для ручной публикации в TikTok.

## Что он делает автоматически

1. Выбирает новую evergreen-тему через Mistral или принимает тему вручную.
2. Находит статью Wikipedia и использует её как фактический источник.
3. Mistral делает оригинальный сценарий на ~190–220 слов и разбивает его на 12–16 сцен.
4. Для каждой сцены Mistral создаёт отдельные визуальные поисковые запросы.
5. Pexels API ищет отдельный вертикальный видеоклип под каждую сцену; один и тот же Pexels ID повторно не используется в ролике.
6. `edge-tts` создаёт английскую озвучку и таймкоды субтитров.
7. FFmpeg приводит все сцены к 1080×1920/30 fps, собирает ролик и накладывает крупные субтитры.
8. Если ролик неожиданно короче 1 минуты, аудио и субтитры автоматически слегка растягиваются до безопасной длительности.
9. GitHub Actions сохраняет готовый `video.mp4` как Artifact.

В `output/` также попадают:

- `video.mp4` — готовый ролик;
- `caption.txt` — подпись;
- `script.txt` — финальный текст озвучки;
- `captions.srt` — субтитры;
- `plan.json` — сцены и поисковые запросы;
- `metadata.json` — источник Wikipedia и использованные Pexels-клипы.

## Что нужно настроить один раз

В репозитории открой `Settings → Secrets and variables → Actions → Secrets` и создай два секрета:

- `MISTRAL_API_KEY`
- `PEXELS_API_KEY`

Опционально в `Variables` можно создать `MISTRAL_MODEL`. По умолчанию используется `mistral-small-latest`.

Никаких API-ключей в файлы проекта вставлять не нужно.

## Запуск

### Вручную

`Actions → Generate TikTok Video → Run workflow`

Поле `topic` можно оставить пустым — Mistral сам выберет тему. В поле `niche` можно написать, например:

`science mysteries and engineering`  
`business history without investment advice`  
`weird technology history`

После завершения запуска скачай Artifact `tiktok-video-...`. Внутри будет `video.mp4`.

### Автоматически

Workflow уже содержит cron один раз в сутки. GitHub cron работает по UTC. При необходимости измени строку в `.github/workflows/generate-video.yml`:

```yaml
- cron: "17 8 * * *"
```

## Локальный запуск

Нужны Python 3.11+ и FFmpeg.

```bash
pip install -r requirements.txt
export MISTRAL_API_KEY="..."
export PEXELS_API_KEY="..."
python generate_video.py
```

PowerShell:

```powershell
$env:MISTRAL_API_KEY="..."
$env:PEXELS_API_KEY="..."
python generate_video.py
```

## Важные замечания

- Pexels иногда не имеет идеального ролика под очень специфическую сцену. В таком случае генератор пробует второй поисковый запрос, а если ничего не найдено — создаёт собственную анимированную текстовую карточку, чтобы сборка не падала.
- Скрипт использует Wikipedia как источник фактов и отдельно просит Mistral не добавлять неподтверждённые сведения.
- Генератор не публикует видео в TikTok автоматически. Это сделано намеренно: сначала лучше просматривать результат и тестировать качество/удержание.
- Mistral API может тарифицироваться в зависимости от твоего аккаунта и модели. Сам проект не требует отдельного платного видеосервиса.

## Быстрая проверка перед TikTok

Перед публикацией посмотри ролик целиком и проверь: нет ли неудачного stock-клипа, корректна ли озвучка имён/терминов, нет ли фактической ошибки и длительность больше 60 секунд.
